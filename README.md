# 锐涞经销商管理系统

渠道授权 · SN 进销存 · 异常风控

## 在线原型（GitHub Pages）

👉 **https://cryangle0.github.io/ruilai/**

## 本地预览

用浏览器直接打开 `index.html`，或：

```bash
npx serve .
```

## 原型说明

- 布局与样式对齐财务系统 Web 端：顶栏 + 侧栏 + 青绿主色 `#00a46e`
- 支持切换 **管理后台 / 代理前端**
- 登录页可选择平台管理员、一级代理、二级代理身份（演示用）
- 覆盖功能清单核心页面：代理围栏、SN/商品、采购销售库存、退货、异常、统计、角色日志、扫码绑定等
