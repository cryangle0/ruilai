# 锐涞经销商管理系统

渠道授权 · SN 进销存 · 异常风控

## 在线原型（GitHub Pages）

👉 **https://cryangle0.github.io/ruilai/**

## 本地预览

用浏览器直接打开 `index.html`，或：

```bash
npx serve .
```

## 原型说明

- 布局与样式对齐财务系统 Web 端：顶栏 + 侧栏 + 青绿主色 `#00a46e`
- **可走查完整交互**：本机 `localStorage` 持久化，业务可闭环演示
- 登录身份：平台管理员 / 一级代理 / 二级代理 / 一级子账号（菜单与权限不同）
- 已打通：电子围栏互斥、采购号段校验入库、扫码销售转库存、库存异常预警、用户绑定分步（IP/归属地）、退货审批回退、Tab/筛选/流水等

### 建议走查路径

1. 管理员登录 → 采购单管理 → 审核 `PO…021`，号段填 `RL202608010031-RL202608010040` → 一级库存增加  
2. 切「代理前端」或一级身份 → 创建销售单 → 扫上述已入库 SN → 确认 → 二级库存增加  
3. 用户绑定：改演示 IP 为广东 → 扫二级在库 SN → 超区确认 → 填 `139…` + 非粤地址 → 触发归属地异常  
4. 售后：用户退货再入库 → 再绑隐藏原用户；二级退货由一级审、一级退货由原厂审
