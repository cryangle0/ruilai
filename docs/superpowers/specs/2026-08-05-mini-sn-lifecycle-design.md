# 小程序端 SN 扫码与全生命周期（设计）

## 结论
同站点 `mode=mini` 手机框模拟小程序；用户 + 代理双入口；小程序内跑扫码作业全流程；后台保留号段审核/围栏/角色配置。数据共用 `ruilai_proto_v3`。

## 入口
登录可选：小程序·用户 / 小程序·一级 / 小程序·二级 / 小程序·子账号 → `mode=mini`。

## Tab
- 用户：扫码查验 · 我的绑定 · 履历
- 一级：扫码 · 采购 · 销售 · 库存 · 我的
- 二级：扫码绑定 · 库存 · 售后 · 我的
- 子账号：销售扫码 · 我的

## SN 详情
状态卡 + 生命周期时间轴（`sn.events` + 流水/退货/异常回填）+ 角色情境动作。

## 复用
采购申请、销售确认、绑用户、退货、再销售、异常检测均复用现有业务函数。
