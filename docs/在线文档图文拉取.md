# 从在线文档拉取问题图文

把「问题表里的文字 + 对应截图」完整拉到仓库。按文档类型选手册，不要混用接口。

| 文档类型 | 手册 | 本仓库已落地的批次 |
|----------|------|--------------------|
| 腾讯文档表格 `docs.qq.com/sheet` | [在线文档图文拉取-腾讯文档.md](./在线文档图文拉取-腾讯文档.md) | Roomroom 开发问题记录（8.27 起按日归档） |
| 企业微信智能表格 `doc.weixin.qq.com/sheet` | 流程同腾讯文档：登录后读表 → 落 `issues.json` + 原图；图 CDN 常见 `wdcdn.qpic.cn`，部分链可直接下载 | [问题修改清单-2026-09-08](./问题修改清单-2026-09-08/)（81 条 / 90 张） |
| 飞书多维表格 Bitable | [在线文档图文拉取-飞书多维表格.md](./在线文档图文拉取-飞书多维表格.md) | 财务系统等问题表 |

共同纪律：

- 不要抓 DOM / 快照当数据源（腾讯表、飞书表都不是普通 HTML 表格）。
- 原图不要下成缩略图；条数、文件名、表格行号要对上。
- Cookie / Token 只放环境变量或当次会话，禁止进仓库。
- 产物目录只留 `README.md`、`issues.json`、`images/`。
