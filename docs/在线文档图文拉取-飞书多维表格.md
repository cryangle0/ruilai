# 飞书多维表格（Bitable）图文抓取经验

> 场景：用 chrome-devtools MCP 控制浏览器，从需要登录的飞书在线表格里把「文字内容 + 对应插图」批量导出到本地。
> 本文记录完整思路、关键接口、解码逻辑、踩坑点和可复用脚本，方便以后直接套用。

---

## 1. 背景与难点

飞书的「多维表格 / Base / Bitable」和普通 HTML 表格完全不同：

- **表格是 Canvas 渲染的**：单元格不是 DOM 节点，页面 a11y 快照（snapshot）和 DOM 抓取都拿不到单元格文字、状态、图片。截图只能看，不能复制。
- **需要登录**：飞书是鉴权站点，必须先在浏览器里完成登录，后续请求才带得上 Cookie / session。
- **数据是压缩+编码的**：记录接口返回的不是明文 JSON，而是 `gzip + base64`。
- **附件是二级跳转**：表格里存的是附件 token，不是图片 URL，要再调一个接口把 token 换成带签名的下载地址。

所以核心思路是：**不要去抓界面，直接复用网页自己的内部 API + 浏览器登录态，用 JS 在页面上下文里把数据取下来。**

---

## 2. 整体流程总览

```
1. navigate_page 打开表格链接 → 跳转到登录页 → 由人工登录
2. take_screenshot 确认进入表格，了解列结构（文字列 / 附件列 / 状态列）
3. list_network_requests 找到加载数据的内部接口（records / cdn_url_v2 等）
4. evaluate_script 在页面里 fetch records 接口 → 解 base64+gzip → 拿到全部记录
5. 从页面 Redux store 里取字段定义，把"选项ID"映射成中文标签（如 状态）
6. evaluate_script 调 cdn_url_v2 把附件 token 换成下载 URL
7. evaluate_script fetch 每张图 → arrayBuffer → base64，用 filePath 落盘成 JSON
8. 本地 Python 把 base64 解码成 PNG，并生成 Markdown / JSON
9. 清理临时文件
```

关键点：**第 4~7 步全部在浏览器页面上下文里跑 JS**，这样天然带着登录态和同源权限，绕开 CORS，也不用手动拼 Cookie。

---

## 3. 关键接口清单

以本次的表格为例（token 等需替换成你自己的）：

| 用途 | 方法 | 接口 |
|------|------|------|
| 表格记录（核心数据） | GET | `/space/api/v1/bitable/{objToken}/records?tableId={tbl}&viewId={vew}&offset=0&limit=3000&...` |
| 附件 token → 下载地址 | POST | `/space/api/box/file/cdn_url_v2/` |
| 文档元信息 | GET | `/space/api/meta/?type=8&token={objToken}` |

几个 ID 怎么来：

- **objToken**（如 `E3LSb61Nka0Z2asRBhVcmNJ4ned`）：表格资源 token。在 `list_network_requests` 里随便找一个 bitable 接口的 URL 就能看到，注意它**不等于** URL 里 wiki 的那串 token。
- **tableId / viewId**（如 `tbl2E9BNV2MRINv2` / `vewm2SEpOM`）：直接在页面 URL 的 `?table=...&view=...` 参数里。
- **wiki docToken**（如 `CmViwf1UEiLmpVkuFWEcVb0Jn2g`）：URL 里 `/wiki/` 后面那串，部分接口要用到。

> 找接口的技巧：先 `list_network_requests` 过滤 `xhr/fetch`，再肉眼找 `records`、`clientvars`、`cdn_url`、`datasource` 这类字眼。用 `get_network_request` 看某个请求的请求头/请求体/响应体，能直接拿到正确的参数格式（照抄最稳）。

## 4. 记录接口：解码 base64 + gzip

`records` 接口返回结构是：

```json
{ "code": 0, "data": { "records": "H4sIAAAJ...（base64）", "encoding": 0 } }
```

`data.records` 是 **gzip 压缩后再 base64** 的字符串。在浏览器里可以用原生 `DecompressionStream('gzip')` 直接解，不用引第三方库：

```js
const j = await (await fetch(url, { credentials: 'include' })).json();
const b64 = j.data.records;
const bin = atob(b64);
const bytes = new Uint8Array(bin.length);
for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
const ds = new DecompressionStream('gzip');
const text = await new Response(new Blob([bytes]).stream().pipeThrough(ds)).text();
const data = JSON.parse(text);
```

解出来的 `data` 关键字段：

- `data.tableRecordNum`：总记录数（用来核对有没有漏）。
- `data.groupList[0].recordIDList`：**记录的显示顺序**（数组，按表格行序）。一定要用这个来排序，`recordMap` 是无序对象。
- `data.recordMap`：`{ recordId: { fieldId: { value: ... } } }`，真正的数据。
- `data.resourceMap.attachments`：附件元信息（token、宽高、大小、文件名）。

每个字段的 `value` 格式按字段类型不同：

| 字段类型 | UI类型 | value 形态 |
|----------|--------|-----------|
| 文本 | Text | `[{ "text": "内容", "type": "text" }]`（拼 `.text`） |
| 单选 | SingleSelect | `"optXXXX"`（**只是选项ID，要再映射成标签**） |
| 附件 | Attachment | `[{ attachmentToken, name, width, height, mimeType, size }]` |
| 人员 | User | `{ users: [{ name, userId, avatarUrl }] }` |

## 5. 把"选项ID"映射成中文标签（重要）

单选/多选字段的 value 是 `optXXXX` 这种选项ID，接口里**不带**中文标签。标签藏在页面的 Redux store 里：

```js
const st = window.store.getState();
const fieldMap = st.bitable.Fields['tbl2E9BNV2MRINv2'].fieldMap;
// fieldMap[fieldId].name           → 字段名（如 "状态"）
// fieldMap[fieldId].property.options → [{ id:'optXXXX', name:'待处理', color:0 }, ...]
```

拿到后建一个 `{ optId: 标签 }` 字典即可。

> 怎么发现 `window.store`：先 `Object.keys(window.store.getState())` 看顶层 key，再顺着 `bitable.Fields.{tableId}.fieldMap` 往下挖。如果没有 `window.store`，可以遍历 `window` 上名字带 `store/state/bitable` 的全局对象递归搜你已知的某个选项ID字符串，反查它所在的对象。

本次实际映射结果：

```
optatpN8gP = 待处理
optQ5vUlm4 = 待验收
optvcwQAFt = 已解决
```

字段映射：

```
fldNw4TF1b = BUG名称(Text)
fldQJex5vv = 状态(SingleSelect)
fldNLDfUlf = 附件(Attachment)
fldweK7PUP = 备注(Text)
fldQCnlYun = 负责人(User)
```

## 6. 附件 token → 图片下载地址

记录里只有 `attachmentToken`，要 POST `cdn_url_v2` 换地址。**关键是 `extra` 字段里要带 bitablePerm 权限信息，否则会被拒。** 直接照抄网页发的请求体结构：

```js
const body = JSON.stringify({
  files: [{ file_token: token, width, height, policy: 'allow_up' }, ...],
  extra: JSON.stringify({
    bitablePerm: {
      tableId: 'tbl2E9BNV2MRINv2',
      rev: data.tableRev,                       // 来自 records 解码结果
      attachments: { fldNLDfUlf: { [recordId]: [token] } }  // 附件字段ID → 记录ID → token列表
    }
  })
});
const csrf = (document.cookie.match(/_csrf_token=([^;]+)/) || [])[1] || '';
const resp = await fetch(`${location.origin}/space/api/box/file/cdn_url_v2/`, {
  method: 'POST', credentials: 'include',
  headers: { 'content-type': 'application/json', 'x-csrftoken': csrf },
  body
});
const j = await resp.json();   // j.data: [{ file_token, url, cipher_type, secret, nonce }]
```

返回的 `url` 有两种形态，**坑就在这里**：

1. `https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/{token}`
   → `cipher_type:"0"`，**未加密、可同源 fetch 直接拿到图片字节**。✅ 首选。
2. `https://lf3-drive.feishucdn.com/object/1000/box-file/...`
   → 带 `cipher_type:"1"` + `secret` + `nonce`，是**加密 + 跨域**的，浏览器里 fetch 会直接 `TypeError: Failed to fetch`（CORS）。❌

**解决办法**：遇到 `feishucdn.com` 那种取不到的，改用 stream 直链兜底：

```js
const streamUrl = 'https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/' + token;
// 或同源： location.origin + '/space/api/box/stream/download/all/' + token
```

本次 20 张图里有 2 张第一次返回的是 feishucdn 加密链取不到，用 stream 直链重试后全部成功。

## 7. 图片落盘：浏览器取字节 → base64 → 本地解码

chrome-devtools 的 `evaluate_script` 只能返回 JSON 序列化的值，没法直接返回二进制。所以在页面里把图片转 base64，再用工具的 `filePath` 参数把整段输出落盘成 JSON：

```js
function abToB64(buf){
  let b = '';
  const u = new Uint8Array(buf);
  const c = 0x8000;                       // 分块，避免 String.fromCharCode 参数过多爆栈
  for (let i = 0; i < u.length; i += c) b += String.fromCharCode.apply(null, u.subarray(i, i + c));
  return btoa(b);
}
const buf = await (await fetch(url, { credentials: 'include' })).arrayBuffer();
const b64 = abToB64(buf);
```

> evaluate_script 的 `filePath` 参数会把返回值直接写到本地文件，适合存大段 base64，不用塞进对话里。落盘的 JSON 外层会包一层 `{ "result": ... }`，本地脚本读的时候记得 `d.get('result', d)` 兜一下。

本地 Python 解码并生成文档：

```python
import json, base64, os, re
raw = base64.b64decode(b64_string)
open(os.path.join(img_dir, fname), 'wb').write(raw)
```

校验图片有效性：PNG 文件头应为 `\x89PNG\r\n\x1a\n`，且字节数和元信息里的 `size` 对得上。

## 8. 完整可复用脚本片段

### 8.1 浏览器侧：一次性取全部记录并存到 window

```js
async () => {
  const base = location.origin;
  const objToken = 'E3LSb61Nka0Z2asRBhVcmNJ4ned';
  const tableId = 'tbl2E9BNV2MRINv2';
  const viewId  = 'vewm2SEpOM';
  const url = `${base}/space/api/v1/bitable/${objToken}/records`
            + `?tableId=${tableId}&viewId=${viewId}&tableRev=403&depRev=%7B%7D`
            + `&viewLazyLoad=true&offset=0&limit=3000&tableID=${tableId}&viewID=${viewId}&removeFmlExtra=true`;
  const j = await (await fetch(url, { credentials:'include' })).json();
  const bin = atob(j.data.records);
  const bytes = new Uint8Array(bin.length);
  for (let i=0;i<bin.length;i++) bytes[i]=bin.charCodeAt(i);
  const ds = new DecompressionStream('gzip');
  const text = await new Response(new Blob([bytes]).stream().pipeThrough(ds)).text();
  window.__feishuData = JSON.parse(text);
  return { total: window.__feishuData.tableRecordNum };
}
```

### 8.2 浏览器侧：抽取需要的行（含状态映射）

```js
async () => {
  const data = window.__feishuData;
  const order = data.groupList[0].recordIDList;
  const fieldMap = window.store.getState().bitable.Fields['tbl2E9BNV2MRINv2'].fieldMap;
  const statusMap = {};
  for (const o of fieldMap['fldQJex5vv'].property.options) statusMap[o.id] = o.name;
  const out = [];
  let row = 0;
  for (const rid of order) {
    row++;
    const rec = data.recordMap[rid];
    const name = (rec.fldNw4TF1b?.value||[]).map(x=>x.text).join('');
    const status = statusMap[rec.fldQJex5vv?.value] || '(无)';
    const remark = (rec.fldweK7PUP?.value||[]).map(x=>x.text).join('');
    const atts = (rec.fldNLDfUlf?.value||[]).map(a=>({token:a.attachmentToken,name:a.name,w:a.width,h:a.height,mime:a.mimeType}));
    out.push({ row, recordId: rid, name, status, remark, attachments: atts });
  }
  window.__rows = out.filter(r => r.status === '待处理');   // 按需筛选
  return { picked: window.__rows.length };
}
```

### 8.3 浏览器侧：token 换地址 + 抓图为 base64（用 filePath 落盘）

```js
async () => {
  const data = window.__feishuData, rows = window.__rows;
  const files = [], perm = {};
  for (const r of rows) for (const a of r.attachments) {
    files.push({ file_token:a.token, width:a.w, height:a.h, policy:'allow_up' });
    (perm[r.recordId] = perm[r.recordId]||[]).push(a.token);
  }
  const extra = JSON.stringify({ bitablePerm:{ tableId:'tbl2E9BNV2MRINv2', rev:data.tableRev, attachments:{ fldNLDfUlf: perm } } });
  const csrf = (document.cookie.match(/_csrf_token=([^;]+)/)||[])[1]||'';
  const j = await (await fetch(`${location.origin}/space/api/box/file/cdn_url_v2/`, {
    method:'POST', credentials:'include',
    headers:{ 'content-type':'application/json','x-csrftoken':csrf },
    body: JSON.stringify({ files, extra })
  })).json();

  const abToB64 = buf => { let b='';const u=new Uint8Array(buf);const c=0x8000;
    for(let i=0;i<u.length;i+=c)b+=String.fromCharCode.apply(null,u.subarray(i,i+c));return btoa(b); };
  const stream = t => 'https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/' + t;

  const images = {}, errors = [];
  for (const f of j.data) {
    const urls = [f.url, stream(f.file_token)];   // 优先官方返回，失败兜底 stream 直链
    let ok = false;
    for (const u of urls) {
      try {
        const r = await fetch(u, { credentials:'include' });
        if (!r.ok) continue;
        const ct = r.headers.get('content-type')||'';
        if (!ct.startsWith('image')) continue;
        images[f.file_token] = { b64: abToB64(await r.arrayBuffer()), mime: ct };
        ok = true; break;
      } catch(e) {}
    }
    if (!ok) errors.push(f.file_token);
  }
  return { rows, images, errors };   // 配合 evaluate_script 的 filePath 落盘
}
```

### 8.4 本地：解码图片 + 生成 Markdown

```python
import json, base64, os, re
BASE = r'输出目录'; IMG = os.path.join(BASE, 'images'); os.makedirs(IMG, exist_ok=True)
d = json.load(open(os.path.join(BASE,'_dump.json'),encoding='utf-8')); d = d.get('result', d)
rows, images = d['rows'], d['images']
safe = lambda s: re.sub(r'[\\/:*?"<>|\r\n\t]', '_', s).strip()[:60]
tok2file = {}
for r in rows:
    for i, a in enumerate(r['attachments'], 1):
        if a['token'] not in images: continue
        fn = f"{r['row']:02d}_{safe(r['name'])}_{i}.png"
        open(os.path.join(IMG, fn),'wb').write(base64.b64decode(images[a['token']]['b64']))
        tok2file[a['token']] = fn
md = ['# 导出清单\n']
for n, r in enumerate(rows, 1):
    md += [f'## {n}. {r["name"]}', '', f'- 状态：{r["status"]}']
    if r['remark']: md.append(f'- 备注：{r["remark"]}')
    md.append('')
    for a in r['attachments']:
        if tok2file.get(a['token']): md += [f'![{a["name"]}](images/{tok2file[a["token"]]})', '']
    md += ['---','']
open(os.path.join(BASE,'导出清单.md'),'w',encoding='utf-8').write('\n'.join(md))
```

## 9. 踩坑清单（重点）

1. **别抓 DOM/快照**。Bitable 是 canvas，单元格不在 DOM 里。一律走内部 API。
2. **记录顺序用 `groupList[].recordIDList`**，不要用 `recordMap` 的 key 顺序。
3. **状态/单选是选项ID**，中文标签在 `store.getState().bitable.Fields[tableId].fieldMap[fid].property.options`。
4. **objToken ≠ wiki token**。records 接口用的是资源 objToken（在已有网络请求里找），不是 URL 上的 wiki token。
5. **cdn_url_v2 必须带 `extra.bitablePerm`**，否则没权限。结构照抄网页请求体最稳。
6. **图片两种链接**：`feishucdn.com`（加密+跨域，浏览器 fetch 必失败）vs `internal-api-drive-stream.feishu.cn/.../download/all/{token}`（明文，可直取）。失败时用 stream 直链兜底重试。
7. **二进制不能直接 return**，转 base64；`String.fromCharCode` 要分块（0x8000）防爆栈；大数据用 evaluate_script 的 `filePath` 落盘。
8. **落盘 JSON 外层包了 `{result:...}`**，本地读取 `d.get('result', d)`。
9. **校验完整性**：核对 `tableRecordNum`、每张图字节数 vs 元信息 `size`、PNG 文件头签名。
10. **登录态有时效**：session / `passport_app_access_token` 会过期，长任务中途失败先检查是否要重新登录或刷新页面。
11. **`limit` 给大点**（如 3000）一次拉完，避免分页 offset 拼接。
12. **CSRF**：POST 类接口带上 `x-csrftoken`（取自 cookie `_csrf_token`）更稳。

---

## 10. 一句话总结

> 飞书 Bitable 抓图文 = 「人工登录拿登录态」+「在页面里直接 fetch records 接口并 gzip 解码」+「从 Redux store 补全选项标签」+「cdn_url_v2 换图片直链（feishucdn 失败就走 stream 兜底）」+「图转 base64 落盘后本地生成 Markdown」。全程在浏览器同源上下文跑 JS，是绕开 canvas 渲染和 CORS 的关键。
